FASE 1: ACQUISIZIONE UNIFICATA

Input Flessibile

Carica qualsiasi tipo di immagine: foto di interi cassetti entomologici, scatole con reperti misti, o scatti di singoli campioni. Il sistema accetta tutto in un unico punto d'ingresso.

Flusso Analisi Massiva

Ottimizzato per inventariare rapidamente scatole con molti esemplari (es. Insetti)

FASE 2: RICONOSCIMENTO VISIVO
Object Detection

L'AI scansiona la foto d'insieme. Individua, conta e separa i singoli individui, creando ritagli digitali per ciascun reperto.

FASE 3: DECODIFICA INTELLIGENTE
Classificazione Tassonomica

Agli oggetti isolati viene assegnata una classe predittiva e generati i metadati di base (Tassonomia presunta, Codice univoco).

FASE 4: DATI STANDARDIZZATI
Export Inventariale

Output dei dati relativi al codice assegnato, specie e tipo nomenclaturale.

Domande Frequenti

Che differenza c'è tra MIDS-1 e MIDS-3? +

Il livello MIDS-1 (Minimum Information about a Digital Specimen) corrisponde a un inventario di base (c'è un oggetto, ha un ID). Il MIDS-3 è un record completo con dati ricchi, inclusi località, date ed etichette trascritte. NEST supporta entrambi a seconda delle necessità.

Il software legge anche le etichette scritte a mano? +

Assolutamente sì. Utilizziamo modelli LLM avanzati (Large Language Models) capaci di interpretare calligrafie storiche complesse e contestualizzare le abbreviazioni del XIX e XX secolo.

Posso esportare i dati per GBIF? +

Sì, l'output nativo è conforme allo standard Darwin Core, rendendo i dati immediatamente pronti per la pubblicazione su aggregatori globali come GBIF.
