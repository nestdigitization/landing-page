01 Image Capture

High-Resolution
Specimen Imaging

Begin with a calibrated photograph of your specimen display box. The system processes complete entomological collections including specimens, labels, and color calibration charts.

  • Standard museum display format support
  • Integrated color calibration via X-Rite charts
  • Automatic white balance correction
  • Multi-specimen batch processing
02 Object Detection

Intelligent
Object Recognition

Neural networks identify and isolate each specimen, label, and calibration element with sub-pixel precision. Spotlight effects highlight detected objects with confidence scores.

  • Multi-class detection: insects, labels, charts
  • Order-level taxonomic classification
  • Instance segmentation for overlapping items
  • Real-time confidence scoring
03 Data Extraction

Structured
Data Extraction

Each detected object undergoes specialized processing. OCR extracts label text, morphological features are analyzed, and color profiles are generated using calibration data.

  • OCR with historical font recognition
  • Morphometric measurement extraction
  • Taxonomic hierarchy resolution
  • Georeferencing from locality data
